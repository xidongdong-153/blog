# 专栏渲染精简与左侧栏聚焦大纲

## Goal

精简专栏渲染的描述文本，让专栏界面内容聚焦；专栏文章左侧栏只保留大纲，移除描述性文本与返回专栏入口。

## Requirements

### R1 左侧栏只保留大纲（核心）

`SeriesChapterSidebar` 展开态保留：折叠开关、章节搜索框、分组手风琴、章节列表。
移除：专栏标题链接、`// 大纲 · 共 N 讲`、连载状态徽标、底部 `// 查看系列完整大纲 →`。
折叠态改为纯图标按钮（去掉「专栏大纲 / 序号 / 总数」文字微标）。

### R2 列表卡片移除描述段

`SeriesBanner` 移除 2 行描述段；保留标题、状态与讲次 meta、`#标签`、进入专栏入口。

### R3 专栏主页顶部移除描述段

`SeriesDetailPage` 顶部移除描述段；保留标题、状态与收录数、`#标签`、配套开源仓库入口。
章节卡片保持现状：保留描述段、日期与阅读时长。

### R4 章节序号统一为纯数字

所有章节序号由 `01/02` 改为 `1/2/3…`（直接用 `series.order`，不补零）。

### R5 移除所有「第 N 讲」表述

- 专栏主页章节卡片：`第 01 讲` → 纯数字序号。
- 文章页顶部微标：`// 专栏：xxx · 第 N 讲 →` → `// 专栏：xxx →`。
- 文末导轨：去掉 `第 N / M 讲`。

### R6 移动端抽屉同步左侧栏

移动端专栏抽屉移除专栏标题链接、`// 大纲 · 共 N 讲`、`专栏主页 →`，只保留分组章节列表；序号同 R4。

### R7 不改动

- 非专栏文章详情页布局与右侧 TOC。
- 左侧栏折叠态持久化、当前讲高亮、路由切换滚动居中。
- 专栏数据结构 `SeriesDefinition` 与内容文件。

## Out of Scope

- `SeriesDefinition` 字段增删与新增专栏注册项。
- 文末导轨「查看系列完整大纲」与「// 专栏章节导轨」标题（保留现状，仅去掉「第 N/M 讲」）。
