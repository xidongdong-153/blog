# 精简顶栏头像菜单与管理面板文案

## Goal

优化全站界面逻辑与文案风格：

1. 移除顶栏头像下拉菜单中的 AI 配置入口，仅保留站长控制台面板与退出登录；
2. 全面优化管理面板（`/admin`）及各子组件文案，摒弃互联网八股与夸大冗长词汇，改为简洁直观、克制明了的功能性文案；
3. 将极简、克制的界面文案设计风格沉淀至前端开发规范中，指导后续 UI 文案保持一致。

## Requirements

### 1. 顶栏头像菜单精简

- 文件：`src/app/(site)/_components/site/header-auth.tsx`
- 站长登录后，下拉菜单仅展示「控制台」（原「管理面板」）入口和「退出登录」按钮。
- 移除「AI 摘要配置」菜单项（已在控制台功能入口中有明确卡片入口，无需在全局常驻顶栏占用层级）。
- 清理无用的 `Cpu` 等图标导入。

### 2. 管理面板文案精简与风格对齐

- 遵循 `xdd-plain-docs` 规范，不写互联网八股词（如"大盘"、"资产"、"矩阵"、"全链路"等），不写虚词套话，严禁 emoji。
- `src/app/(site)/_components/admin/admin-header.tsx`:
  - 眉标由 `// CONSOLE / WORKSPACE · SYS_ADMIN • 站长专属工作台` 精简为 `// ADMIN • 控制台`。
  - 副标题由"集中掌控全站内容资产、互动待办流、基础设施监控与 AI 模型通道。"改为"查看内容数据、待办审批与系统状态。"
  - 运行时间标签由"运行时间:"改为"运行时间"。
- `src/app/(site)/_components/admin/admin-metrics.tsx`:
  - 眉标由 `// 01. 核心资产与运营大盘 · METRICS_OVERVIEW` 改为 `// 01. 总览`。
  - 4 格指标卡标题精简："文章资产" -> "文章"、"随想笔记" -> "笔记"、"互动评论" -> "评论"、"友链与在线" -> "友链"。
  - 状态胶囊与描述去冗长："全量发布" -> "全部已发布"；"短篇速记与技术点滴，随时同步前台展示。" -> 移除假大空修饰，直接说明统计或状态；评论卡片描述由"已启用社交认证防刷防护与垃圾评论屏蔽。"改为更实际的数据或简明说明。
- `src/app/(site)/_components/admin/admin-pending-links.tsx`:
  - 眉标由 `// 02. 待审核友链申请队列` 改为 `// 02. 待审友链`。
  - 空状态说明由"当前所有友链申请均已处理完毕，全站关系链处于最新健康状态。"改为"暂无待审核的友链申请。"
  - 标签"未标已添加"改为"未添加本站"；按钮"处理审核"改为"审核"。
- `src/app/(site)/_components/admin/admin-recent-comments.tsx`:
  - 眉标由 `// 03. 全站最新评论动态流` 改为 `// 03. 最新评论`。
  - 空状态说明由"全站尚无访客发表评论互动。"改为"暂无评论。"
- `src/app/(site)/_components/admin/admin-portal-matrix.tsx`:
  - 眉标由 `// 04. 全站控制台矩阵 · PORTAL_MATRIX` 改为 `// 04. 快捷入口`。
  - 入口卡片标题与说明精简：
    - "AI 摘要模型管理" -> "AI 摘要配置"，说明改为"配置模型服务商与 API Key。"
    - "友链审批与展示" -> "友链管理"，说明改为"审核申请与管理已上线的友链。"
    - "评论监管与互动" -> "评论管理"，说明改为"查看、置顶与删除文章评论。"
    - "实时访客与活动" -> "在线状态"，说明改为"查看实时访客与在线状态。"；跳转文案改为"查看系统状态"
    - "系统监控与诊断" -> "系统状态"，说明改为"检查数据库连接与运行指标。"
- `src/app/(site)/admin/page.tsx`:
  - 内部注释与布局注释同步更新为简洁文案。

### 3. 界面文案规范沉淀

- 更新 `.trellis/spec/frontend/component-guidelines.md`，追加「界面文案规范」小节：
  - 规定界面眉标、标题、操作按钮、空状态和描述说明文案的极简克制风格。
  - 明令禁止在界面中使用互联网八股词（矩阵、大盘、资产、赋能等）与无意义包装文案。
  - 严禁在界面文案中出现 emoji。
