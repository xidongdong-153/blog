# Mac 活动监听与博客本地验证

## 目标

在当前博客首页展示 Mac 当前活动，真实验证应用切换、终端前后台区分与网页更新。

## 已确认范围

- 桌面应用：QQ、VS Code、Ghostty、ChatGPT、Antigravity、QQ 音乐、WorkBuddy。“QQVSCode”按 QQ 与 VS Code 两个应用处理。
- 终端工具：Pi、agy、claude 单独显示，不能全部显示成 Ghostty。
- 用户允许使用 Herdr 的只读窗格与进程标识；不允许读取终端正文。
- 当前使用是桌面应用焦点与选中终端窗格共同判断的结果。后台运行只表示工具进程仍存活，不代表 AI 正在生成。
- 本轮只在 Mac 与当前博客本地联调，不部署公网、不提交代码。

## 背景事实

- Hammerspoon 1.1.1 已安装；`~/.hammerspoon/init.lua` 加载本地 IPC 和 `presence.lua`。前台事件、停止和恢复已验证。
- 七个桌面应用均已找到安装元数据；Bundle ID 核对结果在 `research/local-presence.md`。
- `agy --help` 确认它是独立 AI CLI，不是 Antigravity 桌面启动命令。
- 当前会话满足 `HERDR_ENV=1`。Herdr CLI 支持 pi、agy、claude，已读到真实 Pi 窗格及焦点标志。
- 博客使用 Next.js App Router、自有服务器部署，开发端口 4400；目前无活动 API。

## 需求

- R1：首页头像附近增加紧凑活动展示，可展开查看后台终端工具；保留现有首页布局与文案。
- R2：只展示七个桌面白名单应用。名称与图标来自已核对的映射，不接受采集端任意文本作为公开内容。
- R3：Herdr 中的 Pi、agy、claude 独立识别。只有桌面前台为 Ghostty 且窗格焦点可信时，标记为当前终端活动。其他已识别实例列为后台运行并按工具合并。
- R4：无法确认焦点时显示运行中或未知，不猜测当前正在使用。Herdr 不可用时仍可显示可信的 GUI 活动，终端检测结果不能保留旧值。
- R5：切到白名单外应用时清除当前应用；停止采集、锁屏、休眠或状态超时后不显示旧活动。
- R6：只在本机传递允许的应用/工具标识和必要状态。禁止上传窗口标题、命令参数、cwd、提示词、聊天内容、终端输出、截图、窗格标题和原始 Herdr 响应。
- R7：采集与页面刷新在正常本地环境下约 5 秒内反映变化；状态超时不超过 20 秒。
- R8：提供明确的本地启动、停止、检查命令，保存脚本源码；不改 Pi、agy、claude 的全局配置或命令入口。

## 非目标

- 公网部署、多设备、历史记录、音乐曲目、AI 生成进度、终端内容分析。
- 本次不保证 Herdr 之外的终端窗格精确识别；此情况必须显示未知或宿主应用，不能误报。
- 不添加用户登录、数据库服务、WebSocket、自动登录启动或其他工具插件。

## 验收标准

- [ ] R1/R2：桌面应用白名单逐项验证映射与展示；至少一个真实 GUI 切换完成从采集到浏览器的联调。
- [ ] R3/R4：三个 CLI 的标识与前后台规则都有自动测试；真实 Pi 窗格验证选中与切出 Ghostty，agy/claude 未实际启动时不能把模拟测试说成真实验证。
- [ ] R5：非白名单、停止、断流过期与锁屏规则通过测试；不要求为测试强制锁屏或关闭用户工具。
- [ ] R6：检查上报 JSON 字段，确认无敏感元数据；缺少或错误密钥的写入被拒绝。
- [ ] R7：记录实际端到端更新时间和超时行为。
- [ ] R8：记录脚本文件、本地服务 URL 和停止命令。
- [ ] 按顺序通过 `pnpm typecheck`、`pnpm lint`、`pnpm format:check`，随后 `pnpm build`；既有错误只报告不顺手修复。
- [ ] 浏览器检查桌面/手机布局、长名称、展开关闭、在线和离线状态。
