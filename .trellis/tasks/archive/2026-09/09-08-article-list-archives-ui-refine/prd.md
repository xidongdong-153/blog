# 优化文章页面时间线入口排版

## 目标

优化文章列表页视觉排版，移除正文列表上方的多余夹层，将按年份归档入口文案精简为“时间线”，整合入顶部工具栏右侧，保持页面流贯通且无冗余模块。

## 需求

1. **清理正文上方夹层**：
   - 移除 `src/app/(site)/blog/page.tsx` 中文章列表正上方的页码信息和“按年份查看全部文章”跳转行。
   - 保证工具栏下方直接衔接首篇内容，消除三明治夹层打断感。
2. **修正文章页副标题**：
   - 将 `src/app/(site)/blog/page.tsx` 顶部的副标题由 `// 文章归档` 改为 `// 写作与手记`，消除与 `/blog/archives` 归档页的概念冲突。
3. **工具栏右侧整合时间线入口**：
   - 按钮文案严格定为“时间线”三字（搭配极简外链标 `↗`）。
   - 在 `src/app/(site)/_components/blog/blog-toolbar.tsx` 中置于排序选项右侧，以轻量边框胶囊展示，与左侧分类胶囊风格呼应。
   - 避免在侧边栏生硬创建“// 归档”独立模块，让侧边栏专注于标签导航。

## 验收标准

- [x] 文章列表正上方无冗余信息栏，分类/排序工具栏到首篇文章留白自然。
- [x] 页面顶部副标题显示为 `// 写作与手记`。
- [x] 工具栏右侧排序区后展示“时间线 ↗”胶囊入口，点击跳转 `/blog/archives`。
- [x] 侧边栏保持纯粹的标签导航，无多余空洞分组。
- [x] 通过质量门禁：`pnpm typecheck`、`pnpm lint`、`pnpm format:check`。
