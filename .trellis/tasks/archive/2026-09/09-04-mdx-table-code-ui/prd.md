# 优化 MDX 表格与代码块展示

## Goal

让技术文章中的表格和代码块更容易扫读：表格在桌面端层次清楚，在移动端不再被强行压窄；带文件名的代码块与正文出版物风格一致，同时保留复制、语法高亮和主题切换能力。

## Background

- MDX 统一由 `src/app/(site)/_components/blog/mdx-content.tsx` 渲染。
- 表格当前只有外框与横向滚动容器，`table` 本身固定为 `w-full`。实测 390px 视口下，四列表格被压到 340px，容器 `scrollWidth` 仍为 340px，长技术名词和中文字段被频繁断行。
- 表格单元格样式主要来自 `@tailwindcss/typography`，当前缺少明确的表头底色、行间层次、统一留白和长内容策略。
- 代码块由 `src/app/(site)/_components/blog/code-block.tsx` 映射 `figure`、`figcaption` 与 `pre`；文件名栏当前使用整条 `bg-muted/40` 工具栏样式，与深色代码正文和文章的扁平出版物风格割裂。
- 复制按钮当前绝对定位在右上角，并通过 `group-hover` 显示；触屏设备没有稳定的 hover 状态。
- `rehype-pretty-code` 已提供 Catppuccin Latte / Mocha 双主题语法高亮，现有 MDX 内容已包含带标题和不带标题的代码块。

## Requirements

1. 表格保持语义化 HTML，不把行列内容转换成卡片或普通列表。
2. 表头、数据行、单元格边界和文本层级清楚，连续阅读时能快速对应列名与内容。
3. 移动端采用平衡阅读策略：表格设置内容最小宽度，短字段尽量单行，描述列允许自然换行，通过表格区域独立横向滚动查看完整内容。
4. 宽表格必须限制在正文区域内，不得撑宽页面；横向滚动应通过保留完整列宽和露出后续内容自然提示，不增加操作说明文案。
5. 表格中的链接、粗体、行内代码及长技术名词不能破坏布局。
6. 重新设计代码块文件名区域，使其成为代码容器的一部分，而不是独立的厚重工具栏。
7. 带标题与不带标题的代码块都保持一致的圆角、边框、内边距和代码正文起始位置。
8. 复制按钮在鼠标、键盘和触屏环境下都可发现、可操作，并保留复制成功反馈。
9. 保留语法高亮、代码语言标识、行高亮、Diff 样式和水平滚动能力。
10. 表格与代码块同时适配亮色、暗色主题，不引入现有语义 token 之外的硬编码颜色。

## Acceptance Criteria

- [x] 现有四列表格在 390px 视口下不再被压缩到 340px 内；页面本身无水平溢出，表格区域可独立横向滚动。
- [x] 728px 左右的正文宽度下，表头、数据行和列间距清晰，单元格内容无重叠或裁切。
- [x] 表格中的长英文包名、中文文本、链接、粗体和行内代码均能正常显示。
- [x] 带 `title="src/server.ts"` 的代码块文件名、复制按钮和代码正文形成统一视觉结构，不发生遮挡。
- [x] 不带标题的代码块仍有完整外框与正确内边距，复制按钮不会覆盖首行代码。
- [x] 复制按钮可通过键盘聚焦，在 390px 触屏布局中始终可见，点击后显示成功状态。
- [x] 代码语言标识、语法高亮、行高亮、Diff 标记和横向滚动保持可用。
- [x] 亮色与暗色主题下文字和边界均清晰，组件未使用硬编码主题颜色。
- [x] 桌面端 1440px 与移动端 390px 的浏览器截图无文本重叠、页面横向溢出或控件位移。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm format:check` 和 `pnpm build` 全部通过。

## Out of Scope

- 不改 MDX 语法、frontmatter 或现有文章内容。
- 不更换 `rehype-pretty-code`、Shiki 主题或 MDX 编译管道。
- 不增加表格排序、筛选、固定列等数据表格功能。
- 不重做正文排版、Callout、图片、视频或目录组件。
