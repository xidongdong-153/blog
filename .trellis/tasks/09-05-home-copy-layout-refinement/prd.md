# 首页文案与内容编排优化

## Goal

优化首页第一印象：用更当代、自然、有记忆点的中文替换当前偏模板化的文案，重新设计 Hero 顶部身份信息，并把首页主要内容区改为「Label 在上、内容在下」的纵向编排。

## Background

当前首页已经具备居中 Hero、最近写作时间线、关于、技能和内容统计，但仍有三类问题：

- Hero 主标题「造东西的人，也让机器造东西。」、tagline、quote 与关于文案含义重复，刻意感较重。
- Hero 顶部把身份、所在地、联系方式并列做成三个小标签，其中两个绿色点使用 `pulse` / `ping` 动画，视觉上接近常见 AI 模板。
- `Section` 在桌面端仍采用左侧标题、右侧内容的双列结构，不符合这次偏好的「上方 Label、下方内容」。

网络研究表明，适合本项目借鉴的电影语言特征是具体时间或地点、简短转折、第一人称观察和适度留白；不直接引用或仿写已有电影台词。用户已选择“克制借鉴”：整体仍像真实的个人开发者在说话，不把 Hero 写成明显的电影独白。Hero tagline 最终选用《魔兽世界》联盟侏儒 NPC 原句 `Daylight’s burning.`，用真实的游戏记忆替代自创励志文案。首页其他文案仍需准确表达作者是使用 TypeScript、Web 与 AI 做产品的独立开发者。

## Requirements

### R1. 首页文案重写

- 主标题采用「有些东西，写出来才算做完。」：表达个人博客把实践整理成文字的用途。
- tagline 使用侏儒 NPC 原句 `Daylight’s burning.`，页面只显示英文；含义为「天光不等人」，表达珍惜时间与继续行动的状态，不承担职业说明。
- 删除 `quote` 字段和 Hero 金句行；它与主标题、tagline 信息重复。
- 关于段落改为：
  - 「这里记着做 Web 产品时留下的问题、弯路和答案。」
  - 「有些来自代码，有些来自和 AI 一起工作的日常。想明白一点，就写下一点。」
- Hero 主 CTA 改为「最近写了什么」，次 CTA 保留「关于我」。
- 首页 Section 文案依次改为「最近写的」「关于我」「常用工具」。
- 文案使用自然中文，技术名词 `TypeScript`、`Web`、`AI`、`GitHub` 保留常见写法。
- 借用具体、克制、有留白的电影对白语言机制，但不引用现有电影台词，不写成模仿名句的段子。
- 不使用「热爱」「探索无限可能」「让机器造东西」「赋能」等空泛或模板化表达。
- 主标题负责留下记忆点，tagline 交代作者在做什么，关于段落补充本站记录的内容；三者不能重复表达同一件事。

### R2. Hero 身份信息重设计

- 去掉当前两个绿色在线点及 `pulse` / `ping` 动画。
- 不再把「独立开发 · 全栈 · 智能体」「上海」「联系我」做成三个同权重胶囊。
- 改为出版物署名式元数据行：「上海 / 独立开发者 / 联系我 ↗」。
- 元数据行使用短横线或细线建立结构，不使用底色、圆点和胶囊轮廓。
- 「上海」与「独立开发者」为静态文本；「联系我 ↗」链接到 `/contact`。
- 地点和联系入口是辅助信息，不与主标题争夺视觉层级。
- 保留头像、SpatialField、主标题、主要 CTA、GitHub 入口和滚动提示。

### R3. 首页 Section 改为纵向编排

- 调整首页 `Section`：Label 位于内容上方，内容在下方；桌面端不再切换为左标题右内容。
- Label 依次显示「01 / 最近写的」「02 / 关于我」「03 / 常用工具」，使用语义化 `h2`。
- 三个 Section 统一使用等宽小字 Label、顶部短线和相同的垂直节奏。
- Label 作为小型导航标记，不与正文标题争夺视觉层级。
- 最近写作时间线、关于正文和技能分组的数据与顺序保持不变。

### R4. 视觉与工程约束

- 保留现有亮暗主题、颜色 token、`Satoshi` + `Newsreader` 字体与 `SpatialField`。
- 不新增图片、第三方 UI 或动画依赖。
- 所有交互在键盘焦点下可辨识；新增动效需要支持 `prefers-reduced-motion`。
- 在 1440px 与 375px 视口检查布局，在亮色与暗色主题检查可读性。

## Out of Scope

- 不调整页头、页脚和其他路由页面。
- 不修改文章、笔记的数据读取与排序逻辑。
- 不改全站配色、字体和路由结构。
- 不直接复刻任何导演、编剧或具体影视作品的已有台词。

## Acceptance Criteria

- [ ] Hero 主标题、最终 tagline 与关于文案自然、信息不重复，读起来不像产品宣传语或 AI 模板。
- [ ] Hero 不再渲染 quote 行，`Profile` 中无废弃 `quote` 字段。
- [ ] 文案保留个人开发者身份与 TypeScript、Web、AI 相关事实，不添加无法证明的经历或成绩。
- [ ] Hero 顶部不再出现绿色脉冲点和三个同权重胶囊，联系方式仍可访问。
- [ ] Hero 信息层在 1440px 和 375px 下层级清楚、无溢出。
- [ ] 最近写的、关于我、常用工具均为上方带序号 Label、下方内容，三段间距和 Label 样式一致。
- [ ] 时间线内容、关于内容来源和技能数据结构保持不变。
- [ ] 亮色与暗色主题下正文、Label、链接和辅助信息清晰可读。
- [ ] `prefers-reduced-motion: reduce` 下没有依赖动画才能理解的信息。
- [ ] `pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`pnpm build` 全部通过。
